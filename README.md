# دليل مهام ووظائف البرلماني في المغرب

مرجع عربي عملي للتعرّف إلى الوظائف التشريعية والرقابية والتمثيلية للبرلماني، وأدوات العمل داخل مجلسي البرلمان.

## تنزيل الكتاب

- افتح ملف [`book.html`](book.html) في المتصفح.
- للطباعة أو حفظ نسخة PDF: اختر **طباعة / Print** ثم **Save as PDF / حفظ بصيغة PDF**. أُعدّ الملف بتنسيق عربي من اليمين إلى اليسار، مع فهرس وروابط داخلية وتنسيق مهيأ للطباعة.

## ملاحظة قانونية

هذا الدليل مادة تثقيفية عامة، وليس استشارة قانونية. يجب التحقق من النصوص الدستورية والقوانين التنظيمية والانتخابية والأنظمة الداخلية بصيغتها الرسمية المحيّنة، خصوصاً عند تطبيق إجراء أو تحديد أجل أو أثر قانوني. وقد تختلف التفاصيل بين مجلس النواب ومجلس المستشارين.
